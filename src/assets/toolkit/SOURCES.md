# Toolkit logo sources

Assets are bundled locally and displayed without cropping, recoloring, or added
backgrounds. Product names are presented beside their icons.

- `power-apps.svg`, `power-automate.svg`, `dataverse.svg`: Microsoft Power Platform
  icon collection, https://learn.microsoft.com/en-us/power-platform/guidance/icons
  (Power-Platform-icons-scalable.zip).
- `azure-functions.svg`, `custom-connectors.svg`: Microsoft Azure architecture
  icon collection, https://learn.microsoft.com/en-us/azure/architecture/icons/
  (Azure_Public_Service_Icons_V25.zip). The generic APIs/custom connectors row
  uses Microsoft's Logic Apps Custom Connector icon.
- `react.svg`: https://react.dev/images/brand/logo_dark.svg
- `typescript.svg`: TypeScript's primary square mark (`ts-logo-128.svg`) from
  https://www.typescriptlang.org/branding/typescript-design-assets.zip
- `node.svg`: https://nodejs.org/static/logos/jsIconGreen.svg
- `javascript.svg`: the established community JavaScript mark from its original
  repository, https://github.com/voodootikigod/logo.js/blob/master/js.svg.
  This is a community mark, not an official language-standard logo.

Microsoft assets retain their original artwork and remain subject to Microsoft's
icon terms. Other logos remain subject to their owners' applicable branding and
trademark guidelines. These identify the documented technologies and do not
indicate endorsement.
