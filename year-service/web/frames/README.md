# Pixelbook winter frames v1

Picker order: **Starry Night** (default), **Evergreen**, **Winterlight**.
Opaque, blank frame backgrounds; photos, captions, signature and Pixel are drawn
separately by the application and are never regenerated as part of a frame.
Built-in imagegen edited the user-approved frame references on 2026-11-15.

Prompt set (common instructions): produce a flat portrait 4:5 reusable background;
remove all photographs, people, dog cutout, text, heart and collage dividers;
leave continuous blank warm ivory paper. No watermark or presentation background.
Keep the central rectangle x=8–92%, y=8–91% clear for app-rendered content.

- Starry Night: retain textured navy border, restrained scattered gold stars,
  starbursts, bottom tree silhouettes and low rolling navy hills.
- Evergreen: retain textured deep green border and small pinecone-and-needle
  clusters only at top right and bottom left, tucked away from the photo area.
- Winterlight: retain warm ivory paper and delicate pine sprigs/pinecones at
  top right and bottom left, with no dark border.

Files are versioned so saved exports and already-submitted proofs remain immutable.
